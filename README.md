## 全体像

```
L1 Market Sensing   競合OTAレート／市場需要／イベント／自社ピックアップを毎日自動収集
        ↓
L2 Decision Engine  需要予測 → 推奨ADR・最低宿泊日数を算出（要因分解つき）
        ↓
L3 Distribution     サイトコントローラー経由でOTA・自社予約エンジンへ自動配信

   G1 Rate Policy as Code   経営が決めるのはパラメータだけ（Git管理・変更履歴＝意思決定の記録）
   G2 Operating Rhythm      週次15分・月次RM委員会・四半期パラメータ改定
```

## 主要な提言

1. **「Buy the plumbing, Build the brain」** — レート収集はコモディティなので買う。価格の決め方は施設固有の資産なので自社で持つ
2. **純ADR（手数料控除後）で最適化する** — 表示ADRでの判断は利益を毀損する
3. **5室ゆえに「縮小推定」が要る** — データが薄い日は基準価格へ引き戻し、価格の乱高下を構造的に防ぐ
4. **値下げ禁止則** — 直前値下げはブッキングカーブを恒久的に後ろ倒しにする。埋めるのは価格ではなく価値で
5. **自前スクレイピングはゼロで設計する** — 公式API＋ライセンス済みデータで必要情報の大部分が揃う

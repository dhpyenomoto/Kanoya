# Kanoya — 奈良春日 鹿のや レベニューマネジメント基盤

全5室のオーベルジュ「奈良春日 鹿のや」において、レベニューマネジャーの経験・力量に
依存しない形で ADR と稼働率を最適化するための、システム構想ドキュメント。

## ドキュメント

| ファイル | 内容 |
|---|---|
| [`docs/01_revenue-management-system-proposal.md`](docs/01_revenue-management-system-proposal.md) | RM-OS 構想提案書（本体）。データ収集設計、需要予測、Bid Price 最適化、ガバナンス、OTA戦略、ロードマップ、ROI |

## 提案の骨子

```
L6  検証・学習ループ        予測精度 / Override成績 / 価格実験
L5  配信レイヤー            サイトコントローラー → OTA 自動反映
L4  ガバナンスレイヤー      Pricing Policy Document / ガードレール / 監査ログ
L3  最適化エンジン          Bid Price 動的計画法（5室ゆえに厳密解が解ける）
L2  予測エンジン            階層ベイズ需要モデル（スパースデータ対応）
L1  データ基盤              as_of_date × stay_date の二次元スナップショット
L0  データ取得              競合レート / Google Places / 自社PMS / イベント
```

**設計原則:「人はパラメータを触る。価格は触らない。」**

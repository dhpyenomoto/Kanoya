前提と限界

  1. Google Places API は競合施設の宿泊料金を返さない。本ダッシュボードが推定するのは 需要であり、レートではない。実レートは正規ライセンスの レートショッパー（メトロエンジン等）で別途取得し、この需要判断と突き合わせる。
  2. OTA画面・Googleホテル検索画面のスクレイピングは規約違反であり、本システムには実装していない。
  3. レビューは滞在から平均10日遅れて投稿されるものとして滞在日に引き戻している。 投稿遅延の分布は施設ごとに異なるため、直近10日の推定値は不安定。
  4. オーベルジュ・レストラン併設施設は外来客のレビューが混在する。 config.json の restaurant_review_share で控除しているが、これは推定値であり感度分析が必要。
  5. 全5室という母数では日次の稼働率は 0/20/40/60/80/100% しか取らない。 本手法は90日窓の集計でのみ意味を持つ。日次の需要予測には使えない。
  6. 推定稼働率の絶対値を投資家向け資料やオーナー報告にそのまま転載しないこと。 用途は自社の値付け判断に限る。
